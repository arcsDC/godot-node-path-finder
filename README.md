# godot-node-path-finder

A reusable Godot 4 helper that finds nodes by name or script type with optional depth limits.

## Stack

Primary language: **GDScript**

## Project structure

- `addons/node_path_finder/node_path_finder.gd` — Provides static utility functions to locate nodes in the scene tree by name, script, or class.
- `addons/node_path_finder/plugin.cfg` — plugin metadata

## Usage

Review the source files and install any dependencies referenced by the project before running it.
